# Referensi Source Lama

File di folder ini disalin dari proyek `se2026-lanjutan` untuk referensi adaptasi mekanisme PDF LPD, PDF kwitansi, dan Excel kwitansi. File tidak dipanggil langsung oleh aplikasi baru karena masih menggunakan skema tabel, autentikasi, dan periode kegiatan lama. Integrasi dilakukan bertahap dengan menyesuaikan query ke skema SIPACAK.
